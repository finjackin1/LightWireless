LightWireless - Avisos de terceiros
====================================

O LightWireless é distribuído sob a GPLv3 (ver LICENSE). Este arquivo lista
o software de terceiros que ele usa e sob que licença.

    https://github.com/jasonacox/tinytuya

    chave local da lâmpada. Mantido pela Tuya.

    Licença: BSD-3-Clause (Copyright Lars Heuer)
    https://github.com/heuer/segno


O QUE NÃO É DEPENDÊNCIA
-----------------------

Os atalhos globais NÃO usam biblioteca de teclado. O registro da combinação
é feito pela API oficial do Windows (`RegisterHotKey`), chamada por `ctypes`,
que faz parte da biblioteca padrão do Python. Nenhum gancho de teclado é
instalado e o programa não vê o que é digitado fora das combinações que ele
mesmo registrou.

O mesmo vale para os cantos arredondados da janela, o início com o Windows
(Agendador de Tarefas) e a leitura de qual programa está em primeiro plano:
tudo pela API do próprio Windows, via `ctypes`.
